This project is a production-grade fullstack application.

Goal:
Build a scalable notes/transcription system that will later integrate AI features.

The system will:
- Allow users to login with Google
- Store user data in PostgreSQL
- Expose a REST API with FastAPI
- Use Next.js as frontend
- Run entirely in Docker
- Be developed inside DevContainers in Cursor

Non-functional priorities:
- Scalability
- Clean architecture
- Easy to extend with AI services later
- Easy to test
- Easy to deploy to cloud (AWS in future)

The developer working on this project is experienced but wants the AI to think like a senior architect and enforce best practices.
